# **App Name**: DayFlow

## Core Features:

- Event Creation: Add new events with specific dates, times, and descriptions.
- Reminder System: Set up reminders for upcoming events.
- Calendar View: View a calendar displaying all scheduled events.
- Task Completion: Mark tasks as complete.

## Style Guidelines:

- Background color: Light blue (#E0F7FA), providing a calm and clean base.
- Primary color: Soft blue (#64B5F6) for interactive elements, chosen for a gentle, unobtrusive feel.
- Accent color: Pale cyan (#B2EBF2) to highlight important actions and notifications.
- Body and headline font: 'PT Sans', a humanist sans-serif.
- Simple, line-based icons to represent tasks and appointments.
- Clean and spacious layout for easy readability.
- Subtle animations when tasks are marked as complete or reminders are triggered.
